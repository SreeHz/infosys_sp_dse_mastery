"Touch of Basics" Python Cushion

Why Hash Maps make lookups O(1) and the indispensable {0: 1} base case.

1. Hash Maps in RAM O(1) Lookup

In a list, x in arr checks element-by-element taking O(N). In a Python dict, Python computes hash(x) to jump directly to a memory bucket in O(1)!

target in list = 100,000 steps
target in dict = 1 step
2. The {0: 1} Base Case Exam Lifesaver

Always initialize: prefix_counts = {0: 1}. An empty prefix before the array begins has sum 0. Without this, any subarray starting from index 0 where curr_sum == k is missed!

prefix_counts = {0: 1}
# Subarray [0..i] has sum == k
# need = k - k = 0 (Found in map!)
3. dict.get() Clean Syntax Fast Coding

Avoid clumsy if key in d: d[key] += 1 checks that trigger KeyError bugs under exam stress. Use:

d[key] = d.get(key, 0) + 1
# Or: from collections import defaultdict
# d = defaultdict(int)

The 3-Gear Code Escalator

Time: O(N^2) | Space: O(1) Passed 4/12 test cases (Samples only) 
def solve_gear1_brute(nums: list[int], k: int) -> int:
    n = len(nums)
    count = 0
    
    # Check all pairs of start and end indices
    for i in range(n):
        running_sum = 0
        for j in range(i, n):
            running_sum += nums[j]
            if running_sum == k:
                count += 1
                
    return count

def solve_gear3_optimal(nums: list[int], k: int) -> int:
    # Base case: empty prefix sum 0 occurred once
    prefix_counts = {0: 1}
    curr_sum = 0
    total_subarrays = 0
    
    for num in nums:
        curr_sum += num
        need = curr_sum - k
        
        # Add all occurrences of the complement prefix sum
        if need in prefix_counts:
            total_subarrays += prefix_counts[need]
            
        # Record current prefix sum
        prefix_counts[curr_sum] = prefix_counts.get(curr_sum, 0) + 1
        
    return total_subarrays

Warmup Easy LC 1

Two Sum

Find two numbers in nums that add up to target. The universal pattern that establishes O(1) hash complement lookups.

Open LeetCode 1 ↗
💡 Hint 1: Visual Pattern (15 Mins)

As you iterate through the list, check if (target - num) is already in your hash map.

📐 Hint 2: Transition Logic

seen[num] = index. If target - num in seen: return [seen[target - num], i].

🐍 Hint 3: Annotated Python Solution 
def twoSum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        diff = target - num
        if diff in seen:
            return [seen[diff], i]
        seen[num] = i

Subarray Sum Equals K

Return total count of continuous subarrays whose sum equals K. Identical to today's Infosys Mana Crystal Vine problem!

Open LeetCode 560 ↗
💡 Hint 1: Visual Pattern (15 Mins)

Maintain running sum. Check if (curr_sum - k) is in hash map. Remember {0: 1}!

📐 Hint 2: Transition Logic

ans += map[curr_sum - k]. map[curr_sum] += 1.

🐍 Hint 3: Annotated Python Solution 
def subarraySum(nums, k):
    count = {0: 1}
    cur, ans = 0, 0
    for x in nums:
        cur += x
        ans += count.get(cur - k, 0)
        count[cur] = count.get(cur, 0) + 1
    return ans
SP Boss Hard LC 974

Subarray Sums Divisible by K

Return the count of non-empty subarrays with sum divisible by K. Requires combining Prefix Sum with Modular Arithmetic.

Open LeetCode 974 ↗
💡 Hint 1: Visual Pattern (15 Mins)

If two prefix sums share the same remainder modulo K, the segment between them is divisible by K!

📐 Hint 2: Transition Logic

rem = (curr_sum % k + k) % k. ans += count[rem]. count[rem] += 1.

🐍 Hint 3: Annotated Python Solution 
def subarraysDivByK(nums, k):
    count = {0: 1}
    cur, ans = 0, 0
    for x in nums:
        cur += x
        rem = (cur % k + k) % k
        ans += count.get(rem, 0)
        count[rem] = count.get(rem, 0) + 1
    return ans

🛡️ Tactical Hacks & Partial-Marks Vault for Day 02

The Negative Modulo Normalization Hack: Always compute remainders as (x % k + k) % k. In Python, -2 % 5 == 3, but writing it with the standard offset guarantees cross-platform correctness and eliminates negative key misses.
The Single Pass O(N) Space Trick: You do NOT need to create a separate prefix_sum = [] list. Keep a single integer curr_sum that accumulates on the fly. This halves memory consumption and avoids list allocation latency!
