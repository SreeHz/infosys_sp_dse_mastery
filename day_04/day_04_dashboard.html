Module 1: "Touch of Basics" Python Cushion

The Memory Reality of Slicing vs. True $O(1)$ Window Mechanics

⚠️ THE HIDDEN SLICING TRAP O(k) Hidden Copy

Beginners often write sub = arr[i:i+k] inside a loop. In CPython, list slicing does not create a view; it allocates a brand new list in heap memory and copies all $k$ pointers!

# ❌ WRONG: O(N * k) hidden copies -> 10^5 * 10^4 = 10^9 ops (TLE!)
for i in range(len(arr) - k + 1):
window = arr[i:i+k] # Allocates new memory every step!
curr_sum = sum(window) # Another O(k) pass!
✅ THE O(1) SLIDING ENGINE O(1) Time • O(1) Extra RAM

Notice that between step i and i+1, exactly one element leaves on the left and one enters on the right. Never re-sum! Just add and subtract the boundary delta.

# ✅ OPTIMAL: Pure O(1) delta arithmetic (10^5 steps = 15 ms!)
window_sum = sum(arr[:k]) # Only 1 initial O(k) setup
for right in range(k, len(arr)):
window_sum += arr[right] - arr[right - k] # O(1) drop & add!

Dynamic Variable Window: The Rubber-Band State Machine

In variable sliding window problems (e.g., longest substring, subarray counting), think of the window as a rubber band between two hands left and right:

1. Greedy Stretch (Right) Advance right pointer by 1 step. Incorporate arr[right] into the frequency dictionary.
2. While Loop Contraction If window condition is violated (e.g. distinct > K), shrink left inward, decrementing counts until valid.
3. Monotonic Subarray Harvest Every subarray ending at right starting between left..right is valid: count += (right - left + 1)!

Module 3: The 3-Gear Code Escalator

Brute Force $\rightarrow$ Bottleneck X-Ray $\rightarrow$ Tactical Optimal Blueprint

Nested loops checking every pair $(i, j)$ with a hash set. Simple to write in 4 minutes! Time: O(N²) • Space: O(N) 
def solve_gear1_brute(arr: list[int], k: int) -> int:
    """
    Gear 1: Human Brute Force
    Guarantees ~30% marks on small tests (N <= 1000).
    """
    n = len(arr)
    ans = 0
    for i in range(n):
        distinct = set()
        for j in range(i, n):
            distinct.add(arr[j])
            if len(distinct) == k:
                ans += 1
            elif len(distinct) > k:
                break  # Adding more elements will only increase distinct count!
    return ans
🔍 THE QUADRATIC RECOMPUTATION X-RAY 5 × 10⁹ Operations on N = 10⁵

When $N = 100,000$ and $K$ is moderate-to-large, the inner loop for j in range(i, n) re-scans the same elements millions of times:

Outer loop i = 0: scans arr[0..N-1] (100,000 steps)
Outer loop i = 1: scans arr[1..N-1] ( 99,999 steps) ← Re-reading 99.99% of identical elements!
Outer loop i = 2: scans arr[2..N-1] ( 99,998 steps) ← Re-reading 99.98% of identical elements!
Total Operations: N × (N + 1) / 2 ≈ 5,000,000,000 operations!
Python Budget: ~10⁷ operations/second $\implies$ Requires ~500 SECONDS (TLE after 2.0s)!
The atMost(K) - atMost(K - 1) Monotonic Subarray Frequency Engine. Time: O(N) • Space: O(K) 
from collections import defaultdict

def solve_gear3_optimal(arr: list[int], k: int) -> int:
    """
    Gear 3: Tactical Optimal Solution (100% Score)
    Exact(K) = atMost(K) - atMost(K - 1)
    """
    if k <= 0:
        return 0

    def at_most(limit: int) -> int:
        if limit <= 0:
            return 0
        freq = defaultdict(int)
        left = 0
        distinct = 0
        res = 0

        for right, val in enumerate(arr):
            # 1. Expand right: add element to frequency map
            if freq[val] == 0:
                distinct += 1
            freq[val] += 1

            # 2. Contract left: shrink window while condition is violated
            while distinct > limit:
                left_val = arr[left]
                freq[left_val] -= 1
                if freq[left_val] == 0:
                    distinct -= 1
                left += 1

            # 3. Every subarray starting between left..right and ending at right is valid!
            res += (right - left + 1)

        return res

    return at_most(k) - at_most(k - 1)

Warmup Easy LC 643

Maximum Average Subarray I

Find a contiguous subarray whose length is equal to $k$ that has the maximum average value in $O(N)$ time.

Open LeetCode 643 ↗
💡 Hint 1: Visual Pattern (15 Mins)

Since the window length $k$ is fixed, the maximum average is achieved by the maximum sum! Compute the initial sum of the first $k$ elements, then slide forward.

📐 Hint 2: Transition Logic

In each step from $i = k$ to $N-1$: curr += nums[i] - nums[i - k], then best = max(best, curr).

🐍 Hint 3: Annotated Python Solution 
def findMaxAverage(nums: list[int], k: int) -> float:
    curr = sum(nums[:k])
    best = curr
    for i in range(k, len(nums)):
        curr += nums[i] - nums[i - k]
        if curr > best:
            best = curr
    return best / k
DSE Core Medium LC 3

Longest Substring Without Repeating Characters

Find the length of the longest substring without repeating characters in $O(N)$ time. The staple Infosys DSE Q1 exam question!

Open LeetCode 3 ↗
💡 Hint 1: Visual Pattern (15 Mins)

Use a variable sliding window. Store the last seen index of each character in a dictionary. When a duplicate occurs, jump left forward!

📐 Hint 2: Transition Logic

If char was seen at or after left, update left = last_pos[char] + 1. Then update max length.

🐍 Hint 3: Annotated Python Solution 
def lengthOfLongestSubstring(s: str) -> int:
    last_pos = {}
    left = 0
    ans = 0
    for right, ch in enumerate(s):
        if ch in last_pos and last_pos[ch] >= left:
            left = last_pos[ch] + 1
        last_pos[ch] = right
        ans = max(ans, right - left + 1)
    return ans
SP Boss Hard LC 992

Subarrays with K Different Integers

Given an array of integers, count all subarrays with exactly $K$ distinct numbers in $O(N)$ time. Identical to today's Infosys Telemetry problem!

Open LeetCode 992 ↗
💡 Hint 1: Visual Pattern (15 Mins)

Notice that "at most K" is strictly monotonic, but "exactly K" is not! Use the mathematical decomposition: Exact(K) = atMost(K) - atMost(K - 1).

📐 Hint 2: Transition Logic

Inside atMost(limit), for every right, contract left while distinct > limit. Add (right - left + 1).

🐍 Hint 3: Annotated Python Solution 
from collections import defaultdict

def subarraysWithKDistinct(nums: list[int], k: int) -> int:
    def atMost(m: int) -> int:
        count = defaultdict(int)
        l, res = 0, 0
        for r, x in enumerate(nums):
            if count[x] == 0: m -= 1
            count[x] += 1
            while m < 0:
                count[nums[l]] -= 1
                if count[nums[l]] == 0: m += 1
                l += 1
            res += (r - l + 1)
        return res
    return atMost(k) - atMost(k - 1)

🛡️ Tactical Hacks & Partial-Marks Vault for Day 04

The `(R - L + 1)` Subarray Harvest Law: When sliding window condition is satisfied for range $[L..R]$, EVERY subarray ending at index $R$ starting at $L, L+1, \dots, R$ is automatically valid! Always write res += (R - L + 1) rather than re-scanning.
The Fixed-Size ASCII Array Speedup: When solving substring sliding window with English characters or ASCII, use a fixed list freq = [0] * 128 and index via ord(ch) instead of dict. This runs ~2.5x faster in Python and avoids hash collisions.
