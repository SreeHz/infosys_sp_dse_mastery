The "Extend vs. Restart" Local Decision & The All-Negative Trap

💡 THE EXTEND VS. RESTART INVARIANT O(1) Memory

At any index, you don't need to look at every previous subarray. You only make one greedy decision: "Should I add the current number to the existing running streak, or ditch the past and start fresh right now?"

# Core Kadane Invariant:
curr_sum = max(x, curr_sum + x)
# If curr_sum was negative, (curr_sum + x) < x.
# max() cleanly drops negative baggage in 1 instruction!
⚠️ THE ALL-NEGATIVE INITIALIZATION TRAP Edge Case Bug

If you initialize best_sum = 0, an array with all negative numbers like [-5, -2, -8] will return 0. This is WRONG! The subarray must be non-empty. The correct answer is -2.

# ❌ WRONG: best_sum = 0 returns 0 on all-negative array!
# ✅ CORRECT: Initialize to arr[0] or -float('inf')
curr_max = max_sum = arr[0]

The Circular Subarray Duality Theorem

In a circular ring of length $N$, the maximum subarray can either be:

Case 1: Standard Non-Wrapped Subarray

The subarray lies entirely within the array without crossing the boundaries:
Result = Standard Kadane Max

Case 2: Wrapped Subarray (Spanning Ends)

The subarray wraps around the ends. The center elements are EXCLUDED! Maximizing the included ends is mathematically identical to minimizing the excluded center:
Result = Total Sum - Minimum Subarray Sum

Module 3: The 3-Gear Code Escalator

Brute Force $\rightarrow$ Bottleneck X-Ray $\rightarrow$ Dual-Kadane Blueprint

Nested loops checking all start indices and lengths wrapping with modulo. Simple to write in 3 minutes! Time: O(N²) • Space: O(1) 
def solve_gear1_brute(arr: list[int]) -> int:
    """
    Gear 1: Human Brute Force
    Guarantees ~30% marks on small tests (N <= 1000).
    """
    n = len(arr)
    max_sum = arr[0]
    for i in range(n):
        curr = 0
        for length in range(1, n + 1):
            curr += arr[(i + length - 1) % n]
            if curr > max_sum:
                max_sum = curr
    return max_sum
🔍 THE QUADRATIC MODULO BOTTLENECK 10¹⁰ Operations on N = 10⁵

When $N = 100,000$, testing every starting position $i$ and length $length$ requires:

Outer loop: 100,000 start positions
Inner loop: 100,000 lengths with expensive modulo arithmetic (%)
Total Operations: 100,000 × 100,000 = 10,000,000,000 operations!
Python Execution Time: ~500 SECONDS (Hard TLE after 2.0s limit)!
Dual-Kadane Single-Pass with the All-Negative Guard. Time: O(N) • Space: O(1) 
def solve_gear3_optimal(arr: list[int]) -> int:
    """
    Gear 3: Tactical Optimal Solution (100% Score)
    Dual-Kadane in O(N) time and O(1) space.
    """
    total_sum = 0
    curr_max = 0
    max_sum = arr[0]

    curr_min = 0
    min_sum = arr[0]

    for x in arr:
        total_sum += x

        # 1. Standard Kadane for maximum non-wrapped subarray
        curr_max = max(x, curr_max + x)
        if curr_max > max_sum:
            max_sum = curr_max

        # 2. Inverted Kadane for minimum subarray (to be cut out from wrapped ends)
        curr_min = min(x, curr_min + x)
        if curr_min < min_sum:
            min_sum = curr_min

    # Guard: If all numbers are negative, total_sum - min_sum == 0 (invalid empty array!)
    if max_sum < 0:
        return max_sum

    # Return the maximum between non-wrapped and wrapped subarray
    return max(max_sum, total_sum - min_sum)

def maxSubArray(nums: list[int]) -> int:
    curr = ans = nums[0]
    for x in nums[1:]:
        curr = max(x, curr + x)
        ans = max(ans, curr)
    return ans
DSE Core Medium LC 918

Maximum Sum Circular Subarray

Find maximum subarray sum in a circular array where elements wrap around. Exactly identical to today's Infosys Energy Ring!

Open LeetCode 918 ↗
💡 Hint 1: Visual Pattern (15 Mins)

The answer is either the standard maximum subarray OR total_sum - min_subarray_sum.

📐 Hint 2: Transition Logic

Run standard Kadane for max and inverted Kadane for min in a single pass. Guard: if max_sum < 0: return max_sum.

🐍 Hint 3: Annotated Python Solution 
def maxSubarraySumCircular(nums: list[int]) -> int:
    tot, c_max, m_max = 0, 0, nums[0]
    c_min, m_min = 0, nums[0]
    for x in nums:
        tot += x
        c_max = max(x, c_max + x); m_max = max(m_max, c_max)
        c_min = min(x, c_min + x); m_min = min(m_min, c_min)
    return m_max if m_max < 0 else max(m_max, tot - m_min)
SP Boss Hard LC 1191

K-Concatenation Maximum Sum

Array is repeated consecutively $k$ times up to $10^5$. Find max subarray sum modulo $10^9+7$ in $O(N)$ time.

Open LeetCode 1191 ↗
💡 Hint 1: Visual Pattern (15 Mins)

Never allocate arr * k! For $k > 2$, if total_sum > 0, add (k - 2) * total_sum to the 2-copy cross boundary maximum!

📐 Hint 2: Transition Logic

If $k=1$: Kadane on 1 copy. If $k \ge 2$: ans = max(kadane(arr), max_prefix + max_suffix). If total > 0, add middle copies.

🐍 Hint 3: Annotated Python Solution 
def kConcatenationMaxSum(arr: list[int], k: int) -> int:
    MOD = 10**9 + 7
    def kadane(nums):
        c = m = 0
        for x in nums:
            c = max(0, c + x); m = max(m, c)
        return m
    if k == 1: return kadane(arr) % MOD
    tot = sum(arr)
    ans2 = kadane(arr * 2)
    if tot > 0:
        return (ans2 + (k - 2) * tot) % MOD
    return ans2 % MOD
