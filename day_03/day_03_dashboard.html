"Touch of Basics" Python Cushion

Two-end pointer bounds, in-place swaps, and why the shorter wall always moves.

1. Two-End Pointers Loop Bounds

Initialize left = 0 and right = len(arr) - 1. Always loop with while left < right:. When left == right, width is 0, so never use <=.

left, right = 0, len(arr) - 1
while left < right:
    width = right - left
2. The Greedy Height Law Mathematical Proof

Area = width * min(h[L], h[R]). Moving the taller line inward shrinks width by 1 while the height remains bounded by the shorter line. It can never increase! The only hope is to move the shorter wall inward.

if height[left] < height[right]:
    left += 1
else:
    right -= 1
3. Atomic Tuple Swaps Pythonic O(1)

In partition problems (e.g. Dutch National Flag or reversing), swap elements in-place with zero temp variables:

arr[left], arr[right] = arr[right], arr[left]
# Evaluates right-hand tuple in memory
# then assigns atomically!

Module 3 • The Escalator

The 3-Gear Code Escalator

Brute Force (5-min safety) → Bottleneck X-Ray → Optimal Two Pointers.

Time: O(N^2) | Space: O(1) Passed 4/12 test cases (Samples only) 
def solve_gear1_brute(height: list[int]) -> int:
    n = len(height)
    max_water = 0
    
    # Try all pairs of gates (i, j)
    for i in range(n):
        for j in range(i + 1, n):
            width = j - i
            current_water = width * min(height[i], height[j])
            if current_water > max_water:
                max_water = current_water
                
    return max_water

def solve_gear3_optimal(height: list[int]) -> int:
    left = 0
    right = len(height) - 1
    max_water = 0
    
    while left < right:
        width = right - left
        h_left = height[left]
        h_right = height[right]
        
        # Calculate current capacity & move the shorter boundary inward
        if h_left < h_right:
            current_water = width * h_left
            left += 1
        else:
            current_water = width * h_right
            right -= 1
            
        if current_water > max_water:
            max_water = current_water
            
    return max_water

Warmup Easy LC 167

Two Sum II - Input Array Sorted

Given a 1-indexed sorted array, find two numbers that sum to target using O(1) extra space.

Open LeetCode 167 ↗
💡 Hint 1: Visual Pattern (15 Mins)

Because the array is sorted, if numbers[left] + numbers[right] > target, moving right inward decreases the sum!

📐 Hint 2: Transition Logic

If sum < target: left += 1. If sum > target: right -= 1. Else return [left+1, right+1].

🐍 Hint 3: Annotated Python Solution 
def twoSum(numbers: list[int], target: int) -> list[int]:
    l, r = 0, len(numbers) - 1
    while l < r:
        s = numbers[l] + numbers[r]
        if s == target: return [l + 1, r + 1]
        elif s < target: l += 1
        else: r -= 1

📐 Hint 2: Transition Logic

🐍 Hint 3: Annotated Python Solution 
def maxArea(height: list[int]) -> int:
    l, r, ans = 0, len(height) - 1, 0
    while l < r:
        ans = max(ans, (r - l) * min(height[l], height[r]))
        if height[l] < height[r]: l += 1
        else: r -= 1
    return ans
SP Boss Hard LC 42

Trapping Rain Water

Given elevation heights, compute total trapped rainwater in O(N) time and O(1) space. The classic Infosys 200-mark test question!

Open LeetCode 42 ↗
💡 Hint 1: Visual Pattern (15 Mins)

Water over bar i is min(left_max, right_max) - height[i]. Use two pointers to track the smaller peak!

📐 Hint 2: Transition Logic

If height[l] < height[r]: water += max(0, left_max - height[l]); left += 1. Else right.

🐍 Hint 3: Annotated Python Solution 
def trap(height: list[int]) -> int:
    l, r = 0, len(height) - 1
    l_max, r_max, water = 0, 0, 0
    while l < r:
        if height[l] < height[r]:
            l_max = max(l_max, height[l])
            water += l_max - height[l]
            l += 1
        else:
            r_max = max(r_max, height[r])
            water += r_max - height[r]
            r -= 1
    return water

🛡️ Tactical Hacks & Partial-Marks Vault for Day 03

The In-Place Atomic Swap Hack: When partitioning arrays (e.g. Dutch National Flag or 0s/1s/2s sorting), write arr[l], arr[r] = arr[r], arr[l]. This compiles into efficient bytecodes with zero tuple overhead!
The 3Sum Duplicate Pruning Rule: Whenever applying two pointers on sorted arrays, always skip identical neighbors: while l < r and arr[l] == arr[l-1]: l += 1. This prevents duplicate sets and eliminates TLE on arrays with thousands of repeated elements!
