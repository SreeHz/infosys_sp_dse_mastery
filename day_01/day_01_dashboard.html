1. Python Lists in RAM O(1) vs O(K)

In Python, lists are contiguous arrays of 64-bit pointers. Accessing arr[i] is instant O(1). But slicing arr[L:R] creates a brand new list in memory taking O(R - L) time!

sum(arr[L:R+1]) in loop = 1010 ops (TLE)
pref[R+1] - pref[L] = 1 op (Instant)
2. The Leading-Zero Miracle Index Hack

Always initialize your prefix array of length N + 1 with a leading 0. Why? It eliminates the dreaded if L == 0 boundary check.

# Sum of arr[0..i] = pref[i + 1]
# Range sum(L..R) = pref[R + 1] - pref[L]

Module 3 • The Escalator

The 3-Gear Code Escalator

Brute Force (5-min safety) → Bottleneck X-Ray → Optimal Difference Blueprint.

Time: O(Q * N) | Space: O(N) Passed 4/12 test cases (Samples only) 
def solve_gear1_brute(n: int, updates: list[list[int]]) -> list[int]:
    # Start with all towers having 0 armor
    armor = [0] * n
    
    # Process each spell one by one
    for l, r, x in updates:
        # Loop over every tower in range [L-1, R-1]
        for idx in range(l - 1, r):
            armor[idx] += x  # <--- REDUNDANT WORK HERE!
            
    return armor
💡 Psychological Win: Anyone can write this code in 3 minutes during an exam. If you are stuck or panicking, write Gear 1 immediately to lock in partial marks before upgrading!

from itertools import accumulate

def solve_gear3_optimal(n: int, updates: list[list[int]]) -> list[int]:
    # Allocate N + 2 to safely handle 1-indexed R + 1 without IndexError
    diff = [0] * (n + 2)
    
    # Step 1: Record boundaries in O(1) time per spell
    for l, r, x in updates:
        diff[l] += x        # Armor increases by X at tower L
        diff[r + 1] -= x    # Effect ends right after tower R
        
    # Step 2: Accumulate running sum over towers 1 to N in O(N)
    return list(accumulate(diff[1:n + 1]))

Range Sum Query - Immutable

Given integer array nums, handle multiple queries for the sum of elements between left and right in O(1) time.

Open LeetCode 303 ↗
💡 Hint 1: Visual Pattern (15 Mins)

Calculate cumulative running sums once in the constructor so you never re-sum repeatedly.

📐 Hint 2: Formula Transition

sumRange(L, R) = prefix[R + 1] - prefix[L].

🐍 Hint 3: Annotated Python Solution 
class NumArray:
    def __init__(self, nums: list[int]):
        self.pref = [0] + list(accumulate(nums))
    def sumRange(self, left: int, right: int) -> int:
        return self.pref[right + 1] - self.pref[left]

Don't add seats to every flight in range. Record +seats at first, -seats after last.

📐 Hint 2: Formula Transition

diff[first] += seats, diff[last + 1] -= seats. Then accumulate.

🐍 Hint 3: Annotated Python Solution 
def corpFlightBookings(bookings, n):
    diff = [0] * (n + 2)
    for l, r, k in bookings:
        diff[l] += k
        diff[r + 1] -= k
    return list(accumulate(diff[1:n + 1]))
