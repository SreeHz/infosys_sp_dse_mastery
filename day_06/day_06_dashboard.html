The Immutability Trap, "".join() Defense & Hashable Tuples

⚠️ THE STRING CONCATENATION TRAP O(N²) Heap Thrashing

In Python, strings are immutable. Writing res += ch inside a loop does not modify memory in place. It allocates a brand-new string and copies all previous characters!

# ❌ WRONG: O(N²) allocation overhead
s = ""
for ch in arr: s += ch
# ✅ OPTIMAL: O(N) list append + join
chars = []; chars.append(ch); s = "".join(chars)
🔑 THE IMMUTABLE TUPLE HASH KEY O(K) vs O(K log K)

To group anagrams, sorting takes $O(K \log K)$. A faster approach is to count character frequencies with ord(ch) - ord('a'). Because lists are mutable and cannot be dict keys, we cast to a tuple(count)!

count = [0] * 26
for ch in word: count[ord(ch) - ord('a')] += 1
key = tuple(count) # Immutable & Hashable!

The 2N - 1 Palindrome Centers Theorem

Every palindromic substring is symmetric around a central reflection axis. In any string of length $N$:

1. Odd Centers (N Centers)

Mirror lies on a single character: expand(i, i).
Example: r a [c] e c a r (Center is 'c').

2. Even Centers (N - 1 Centers)

Mirror lies in the gap between two characters: expand(i, i + 1).
Example: n o | o n (Center is between 'o' and 'o').

Module 3: The 3-Gear Code Escalator

Brute Force $\rightarrow$ Bottleneck X-Ray $\rightarrow$ Expand-Around-Center Blueprint

Nested loops generating every substring and reversing with [::-1]. Writeable in 3 minutes! Time: O(N³) • Space: O(N) 
def solve_gear1_brute(s: str) -> str:
    """
    Gear 1: Human Brute Force
    Guarantees ~30% marks on small tests (N <= 200).
    """
    n = len(s)
    if n <= 1:
        return s

    best_sub = s[0]
    max_len = 1

    for i in range(n):
        for j in range(i + 1, n + 1):
            sub = s[i:j]
            if sub == sub[::-1]:
                if len(sub) > max_len:
                    max_len = len(sub)
                    best_sub = sub

    return best_sub

Expand-Around-Center over 2N - 1 odd/even centers in $O(1)$ auxiliary space. Time: O(N²) • Space: O(1) 
def solve_gear3_optimal(s: str) -> str:
    """
    Gear 3: Tactical Optimal Solution (100% Score)
    Expand-Around-Center in O(N^2) time and O(1) space.
    """
    n = len(s)
    if n <= 1:
        return s

    start = 0
    max_len = 1

    def expand(left: int, right: int) -> tuple[int, int]:
        while left >= 0 and right < n and s[left] == s[right]:
            left -= 1
            right += 1
        # Returns (start_index, palindrome_length)
        return left + 1, right - left - 1

    for i in range(n):
        # 1. Odd-length center at index i (e.g., "aba")
        l1, len1 = expand(i, i)
        if len1 > max_len:
            max_len = len1
            start = l1

        # 2. Even-length center between i and i + 1 (e.g., "abba")
        l2, len2 = expand(i, i + 1)
        if len2 > max_len:
            max_len = len2
            start = l2

    return s[start:start + max_len]

Valid Palindrome

Determine if a phrase is a palindrome after converting all uppercase letters to lowercase and removing all non-alphanumeric characters.

📐 Hint 2: Transition Logic

While not s[l].isalnum(): l += 1. If s[l].lower() != s[r].lower(): return False.

🐍 Hint 3: Annotated Python Solution 
def isPalindrome(s: str) -> bool:
    l, r = 0, len(s) - 1
    while l < r:
        while l < r and not s[l].isalnum(): l += 1
        while l < r and not s[r].isalnum(): r -= 1
        if s[l].lower() != s[r].lower(): return False
        l += 1; r -= 1
    return True
DSE Core Medium LC 5

Longest Palindromic Substring

Find the longest contiguous palindromic substring in $O(N^2)$ time and $O(1)$ auxiliary space. Exactly identical to today's Infosys Nalanda Scroll!

Open LeetCode 5 ↗
💡 Hint 1: Visual Pattern (15 Mins)

Notice that a palindrome mirrors outward. Expand from all $2N - 1$ centers (both odd centers and even gaps) in $O(1)$ space.

📐 Hint 2: Transition Logic

While s[l] == s[r]: decrement l and increment r. Length is r - l - 1.

🐍 Hint 3: Annotated Python Solution 
def longestPalindrome(s: str) -> str:
    start, max_len = 0, 1
    def exp(l, r):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1; r += 1
        return l + 1, r - l - 1
    for i in range(len(s)):
        l1, len1 = exp(i, i)
        if len1 > max_len: max_len, start = len1, l1
        l2, len2 = exp(i, i + 1)
        if len2 > max_len: max_len, start = len2, l2
    return s[start:start + max_len]

Group Anagrams

🐍 Hint 3: Annotated Python Solution 
from collections import defaultdict

def groupAnagrams(strs: list[str]) -> list[list[str]]:
    mp = defaultdict(list)
    for w in strs:
        cnt = [0] * 26
        for ch in w: cnt[ord(ch) - 97] += 1
        mp[tuple(cnt)].append(w)
    return list(mp.values())
